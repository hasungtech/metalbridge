## 1단계 · 저장소 만들기 (15분)

### 1-1. 압축 풀기

`METALBRIDGE_repo.zip` 을 원하는 위치에 풀고, 폴더 이름을 `metalbridge` 로 바꿉니다.
예) `~/projects/metalbridge` 또는 `C:\projects\metalbridge`

### 1-2. 터미널에서 그 폴더로 이동

```bash
cd ~/projects/metalbridge      # Mac
cd C:\projects\metalbridge     # Windows
```

폴더가 맞는지 확인
```bash
ls        # Mac  → CLAUDE.md, package.json, src … 가 보이면 정상
dir       # Windows
```

### 1-3. Git 초기화 및 첫 커밋

```bash
git init
git add .
git commit -m "초기 이관: 파싱 엔진 · 요청서 생성 · 공급처 매칭"
```

### 1-4. GitHub에 빈 저장소 생성

1. github.com → 우측 상단 **+** → **New repository**
2. Repository name: `metalbridge`
3. **Private** 선택 (공급처 정보가 들어 있습니다)
4. README·gitignore·license는 **모두 체크 해제** (이미 있습니다)
5. **Create repository**

### 1-5. 연결하고 올리기

GitHub이 보여주는 주소를 그대로 씁니다.

```bash
git remote add origin https://github.com/사용자명/metalbridge.git
git branch -M main
git push -u origin main
```

브라우저에서 GitHub 저장소를 새로고침해 파일이 보이면 성공입니다.

## 2단계 · Supabase 준비 (20분)

### 2-1. 스키마 실행

1. Supabase 대시보드 → 왼쪽 **SQL Editor** → **New query**
2. 저장소의 `supabase/schema.sql` 파일을 열어 **전체 복사**
3. 붙여넣고 **Run** (우측 하단)
4. `Success. No rows returned` 가 나오면 정상

### 2-2. 만들어졌는지 확인

왼쪽 **Table Editor** 에 아래 6개가 보여야 합니다.

```
rfq            견적 요청 (헤더)
rfq_items      품목 명세
rfq_answers    확인 문답
rfq_files      첨부 파일
rfq_suppliers  발송·회신 추적
suppliers      공급처 마스터
```

왼쪽 **Storage** 에 `rfq-files` 버킷이 있어야 합니다. 없으면 New bucket → 이름 `rfq-files` → Public 체크 해제 → Create.

### 2-3. 키 복사 (중요)

**Project Settings**(톱니바퀴) → **API** 에서 두 개를 메모장에 복사해 두십시오.

```
Project URL      https://xxxxxxxx.supabase.co
anon public key  eyJhbGciOiJI... (매우 긴 문자열)
```

> `service_role` 키는 절대 복사하지 마십시오. 이건 서버 전용이고 유출되면 DB 전체가 열립니다.

### 2-4. 담당자 계정 만들기

**Authentication** → **Users** → **Add user** → **Create new user**
백오피스 로그인에 쓸 이메일·비밀번호를 넣습니다. (백오피스 화면은 다음 단계에서 만듭니다)

## 3단계 · 내 컴퓨터에서 실행 (15분)

### 3-1. 환경변수 파일 만들기

프로젝트 폴더에서

```bash
cp .env.example .env      # Mac
copy .env.example .env    # Windows
```

`.env` 파일을 편집기로 열어 2-3에서 복사한 값을 넣습니다.

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJI...
```

> `.env` 는 `.gitignore` 에 들어 있어 GitHub에 올라가지 않습니다. 정상입니다.

### 3-2. 설치와 실행

```bash
npm install        # 2~3분 걸립니다
npm run dev
```

`http://localhost:5173` 이 뜨면 브라우저로 열어 확인합니다.

### 3-3. 실제로 테스트

1. 첫 화면 문의창에 **견적의뢰 PDF** 를 끌어다 놓습니다
2. 아래 판독표에 **품목 20건** 이 나오는지 확인
3. 문답 9개를 답합니다
4. **② 담당자에게 보내기** 클릭
5. Supabase → Table Editor → `rfq` 테이블에 행이 **1건 생겼는지 확인**

행이 안 생기면 `.env` 값이 잘못된 것입니다. 이 경우 메일 앱이 열립니다.

### 3-4. 회귀 테스트 (선택)

```bash
npx playwright install chromium     # 최초 1회만
npm test
```

## 4단계 · Vercel 배포 (20분)

### 4-1. 프로젝트 가져오기

1. vercel.com → **Add New** → **Project**
2. GitHub 저장소 목록에서 `metalbridge` → **Import**
3. Framework Preset이 **Vite** 로 자동 인식됩니다 (아니면 직접 선택)

### 4-2. 환경변수 등록 (배포 전에 반드시)

Import 화면의 **Environment Variables** 를 펼쳐 두 개를 추가합니다.

| Name | Value |
|---|---|
| `VITE_SUPABASE_URL` | 2-3에서 복사한 URL |
| `VITE_SUPABASE_ANON_KEY` | 2-3에서 복사한 anon key |

**Deploy** 를 누릅니다. 2~3분 뒤 `metalbridge-xxxx.vercel.app` 주소가 나옵니다.

### 4-3. 도메인 연결

1. 프로젝트 → **Settings** → **Domains** → `metalbridge.ai` 입력 → **Add**
2. Vercel이 알려주는 방식으로 등록처(도메인 산 곳) DNS를 설정합니다
   - **A 레코드** 방식: 이름 `@`, 값 `76.76.21.21`
   - **www**: CNAME → `cname.vercel-dns.com`
3. 전파는 보통 1시간, 길면 하루. HTTPS는 자동 발급됩니다

`www.metalbridge.ai` → `metalbridge.ai` 리다이렉트는 `vercel.json` 에 이미 넣어뒀습니다.

### 4-4. 확인

`metalbridge.ai` 접속 → PDF 업로드 → 문답 → 전송 → Supabase `rfq` 테이블에 행 추가 확인.
여기까지 되면 **실제로 영업에 쓸 수 있는 상태**입니다.

## 5단계 · Claude Code 데스크톱 (15분)

### 5-1. 앱에서 폴더 열기

1. Claude 데스크톱 앱 실행
2. **Code** 탭 선택
3. 프로젝트 폴더(`metalbridge`) 를 엽니다
4. `CLAUDE.md` 를 자동으로 읽습니다 — 디자인 시스템·DOM 훅·DB 규칙이 매 세션 적용됩니다

### 5-2. 커넥터 연결 (선택이지만 권장)

설정 → 커넥터에서 두 개를 붙이면 지시 한 줄로 코드·DB가 함께 움직입니다.

- **GitHub** — 커밋·PR 생성
- **Supabase** — 테이블 조회·마이그레이션 실행

### 5-3. 첫 지시

```
design/BRIEF.md 와 design/CONTRACT.md 를 읽고 메인 페이지를 재구성해줘.
DOM 훅 7개(drop, fileInput, askLog, askChips, askIn, specBody, specMeta)와
npm test 는 반드시 통과해야 해.
작업이 끝나면 새 브랜치로 PR을 올려줘.
```

PR을 올리면 Vercel이 **미리보기 URL** 을 자동으로 만듭니다. 그 주소로 확인하고, 괜찮으면 GitHub에서 Merge → `metalbridge.ai` 에 자동 반영됩니다.

## 6단계 · 휴대폰에서 이어받기 (10분)

### 6-1. 세션 시작

컴퓨터 터미널에서 프로젝트 폴더로 이동한 뒤 Claude Code를 실행하고,
세션 안에서 `/mobile` 을 입력하면 QR 코드가 나옵니다.

### 6-2. 휴대폰 연결

1. Claude 앱(iOS·Android) 설치 후 같은 계정으로 로그인
2. QR을 찍거나, 앱의 세션 목록에서 해당 세션을 선택
3. 컴퓨터 아이콘에 초록 점이 켜져 있으면 연결된 상태입니다

### 6-3. 알아두실 점

- **컴퓨터가 켜져 있어야 합니다.** 휴대폰은 조종기이지 실행 주체가 아닙니다
- 대화는 양쪽에서 동기화됩니다. 터미널에서 치던 걸 휴대폰에서 이어서 쳐도 됩니다
- 코드와 파일은 내 컴퓨터에만 있습니다. 휴대폰으로 넘어가지 않습니다
- 컴퓨터를 끄고도 쓰시려면 **Claude Code on the web** 을 쓰십시오. GitHub 저장소를 대상으로 클라우드에서 돌아갑니다

## 문제가 생기면

| 증상 | 원인 | 조치 |
|---|---|---|
| `npm install` 실패 | Node.js 버전 낮음 | `node -v` 확인 후 20 이상으로 설치 |
| 사이트는 뜨는데 3D가 안 보임 | 브라우저 그래픽 제한 | 기능에는 영향 없음. 무시 가능 |
| PDF 올려도 품목이 안 나옴 | 스캔 이미지 PDF | 텍스트가 없는 PDF는 판독 불가. 엑셀로 요청 |
| 전송 시 메일 앱이 열림 | 환경변수 누락 | `.env` 또는 Vercel 환경변수 확인 |
| Supabase에 행이 안 생김 | RLS 정책 미적용 | `schema.sql` 을 다시 실행 |
| 도메인이 안 열림 | DNS 전파 중 | 최대 24시간 대기 |
