# Claude Code 시작하기

저장소를 Claude Code 데스크톱 앱에서 열면 `CLAUDE.md` 를 자동으로 읽습니다.
아래 지시문을 **그대로 복사해 붙여넣으십시오.**

---

## 0. 처음 열었을 때 — 상태 파악

```
이 저장소를 처음 봤어. CLAUDE.md 와 README.md, design/TASKS.md 를 읽고
지금 무엇이 되어 있고 무엇이 남았는지 정리해줘.
코드는 아직 고치지 마.
```

---

## 1. 환경 확인 — 실제로 돌아가는지

```
npm install 하고 npm run dev 로 띄운 뒤,
tests/fixtures 의 샘플 PDF를 올렸을 때 품목 20건이 판독되는지 확인해줘.
안 되면 원인을 찾아 고쳐줘.
```

---

## 2. 백오피스 만들기 — 지금 가장 급한 것

```
design/TASKS.md 의 1번(백오피스 /admin)을 구현해줘.

- Supabase Auth 이메일 로그인, 로그인 안 하면 아무것도 안 보이게
- rfq_board 뷰로 요청 목록, 상태별 필터, 최신순
- 상세 화면: 품목 명세 · 확인 문답 · 첨부 파일 다운로드 · 발송 후보 공급처
- 상태 변경 드롭다운 (접수→확인중→발송준비→발송→회신취합→고객회신→종료)
- 공급처 회신 입력: unit_price, lead_time, replied_at

스타일은 src/styles/tokens.css 변수만 쓰고,
supabase/schema.sql 을 건드려야 하면 그 파일도 함께 고쳐줘.
끝나면 npm test 통과 확인하고 PR 올려줘.
```

---

## 3. 접수 알림

```
design/TASKS.md 의 2번(접수 알림)을 구현해줘.
rfq 테이블에 insert가 일어나면 담당자 메일로 알림이 가야 해.
접수번호·연락처·품목 수·발송 가능 건수·백오피스 링크를 담아줘.
Supabase Edge Function 으로 만들고, 배포 방법을 README 에 적어줘.
```

---

## 4. 공급처 마스터 DB 이관

```
design/TASKS.md 의 3번을 진행해줘.
src/engine/suppliers.js 의 SUPPLIER_MASTER 74곳을 suppliers 테이블 시드 SQL로 만들고,
백오피스에서 추가·수정·비활성화할 수 있게 해줘.

주의: 익명 사용자가 공급처 목록을 조회할 수 없어야 해.
매칭은 서버 쪽(Edge Function 또는 RPC)에서 처리하고 결과만 내려줘.
```

---

## 5. 메인 페이지 재설계 — 문의 월 15건 넘은 뒤에

```
design/HANDOFF_DESIGN.md 와 design/CONTRACT.md 를 읽고 메인 페이지를 재구성해줘.

- 섹션 11개 → 5개, 3D 3개 → 1개
- 업로드 영역이 첫 화면의 가장 큰 요소가 되게
- DOM 훅 7개는 반드시 유지
- 모바일 390px 에서 가로 넘침 없어야 함

Design에서 받은 시안이 있으면 함께 참고할게.
끝나면 npm test 통과 확인하고 PR 올려줘.
```

## 자주 쓰는 명령

저장소에 슬래시 명령을 넣어뒀습니다.

| 명령 | 하는 일 |
|---|---|
| `/review` | DOM 훅·클래스·토큰·문구 규칙 위반 점검 |
| `/ship` | 테스트 → 커밋 → PR 생성 |
| `/design-sync` | design 문서와 코드가 어긋난 부분 보고 |
