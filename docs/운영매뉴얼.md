## 일간 루틴 (30분)

### 아침 10분 — 접수 확인
- Supabase 또는 백오피스에서 새 문의 확인
- **연락처가 있으면 그날 안에 회신**합니다. 없으면 첨부 자료에서 찾습니다
- 확인 필요 항목이 있으면 확인 요청서(엑셀 02시트)를 보냅니다
- 상태를 `확인중` 또는 `발송준비` 로 바꿉니다

### 점심 10분 — 공급처 발송·취합
- 확정 품목은 공급처 발송본(엑셀 ①시트)을 그대로 보냅니다
- **1차 8곳 먼저**, 48시간 내 회신이 3곳 미만이면 2차 발송
- 회신이 온 건은 `rfq_suppliers` 에 단가·납기를 입력합니다

### 저녁 10분 — 고객 회신
- 회신이 2곳 이상 모이면 비교표를 만들어 고객사에 보냅니다
- 전부 기다리지 마십시오. **2곳이면 비교가 됩니다**
- 상태를 `고객회신` 으로 바꿉니다
