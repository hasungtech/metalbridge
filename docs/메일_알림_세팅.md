# 회사 메일 · 접수 알림 세팅 (2026-09-05)

목표 세 가지, 모두 무료 요금제로 됩니다.

1. **받기** — `quote@metalbridge.ai` 로 오는 메일이 `team.metalbridge@gmail.com` 에 도착
2. **보내기** — Gmail 에서 보낼 때 발신자가 `quote@metalbridge.ai` 로 표시
3. **접수 알림** — 사이트에 문의가 접수되면 즉시 메일 도착

소요 시간: 1번 15분 · 2번 10분 · 3번 15분 (DNS 전파 대기 별도, 보통 수 분~1시간)

---

## 1. 받기 — ImprovMX 포워딩 (무료)

가장 가벼운 방법입니다. 메일함을 새로 만들지 않고, 도메인 주소로 온 메일을
지금 쓰는 Gmail 로 넘깁니다.

1. https://improvmx.com 가입 (무료) → 도메인 `metalbridge.ai` 추가
2. 포워딩 규칙: `quote` → `team.metalbridge@gmail.com`
   (겸사겸사 `*`(catch-all) → 같은 주소로 걸어두면 오타 수신도 잡힙니다)
3. **Vercel 대시보드 → 프로젝트 → Settings → Domains → metalbridge.ai → DNS Records**
   (도메인 DNS 를 Vercel 이 아닌 곳에서 관리 중이면 그곳에서) 아래 3개 추가:

| Type | Name | Value | Priority |
|---|---|---|---|
| MX | @ | `mx1.improvmx.com` | 10 |
| MX | @ | `mx2.improvmx.com` | 20 |
| TXT | @ | `v=spf1 include:spf.improvmx.com ~all` | — |

4. ImprovMX 대시보드가 초록불이 되면, 아무 메일로나 `quote@metalbridge.ai` 에
   보내 Gmail 도착 확인

> 대안 — 도메인 DNS 를 Cloudflare 로 옮길 계획이 있으면 Cloudflare Email
> Routing(무료)도 같은 일을 합니다. 지금은 네임서버 이전이 없는 ImprovMX 가 빠릅니다.

## 2. 보내기 — Gmail 에서 quote@ 발신 (Resend SMTP)

3번에서 어차피 Resend 를 쓰므로, 발신도 Resend 하나로 묶습니다.

1. https://resend.com 가입 (무료: 월 3,000통 · 일 100통)
2. **Domains → Add Domain → `metalbridge.ai`** → 안내되는 DNS 레코드 3개를
   1번과 같은 곳에 추가 (send 서브도메인 MX·TXT, `resend._domainkey` DKIM —
   1번 레코드와 충돌하지 않습니다) → Verify
3. **API Keys → Create** (Full access) → 키 복사 (한 번만 보입니다)
4. Gmail(team.metalbridge) → 설정 → **계정 및 가져오기 → 다른 주소에서 메일 보내기 → 메일 주소 추가**
   - 이름: METAL BRIDGE / 주소: `quote@metalbridge.ai` / "별칭으로 취급" 체크
   - SMTP 서버: `smtp.resend.com` · 포트 `465` (SSL)
   - 사용자 이름: `resend` · 비밀번호: **위에서 만든 API 키**
   - 확인 메일이 1번 포워딩을 타고 Gmail 로 오면 인증 완료
5. Gmail 에서 발신 주소 기본값을 `quote@metalbridge.ai` 로 설정 (선택)

## 3. 접수 알림 — Supabase Edge Function

코드는 저장소에 있습니다: `supabase/functions/notify-rfq/index.ts`
문의가 접수되면 접수번호·연락처·품목 수·견적 조건 요약과 백오피스 링크가 메일로 옵니다.

터미널에서 (Supabase CLI 필요 — `npm i -g supabase` 후 `supabase login`):

```bash
cd metalbridge
supabase link --project-ref <프로젝트 REF>   # 대시보드 URL 의 xxxx 부분

supabase secrets set RESEND_API_KEY=<2-3에서 만든 키>
supabase secrets set NOTIFY_TO=team.metalbridge@gmail.com
supabase secrets set NOTIFY_FROM=quote@metalbridge.ai
supabase secrets set HOOK_SECRET=<아무 긴 무작위 문자열>

supabase functions deploy notify-rfq --no-verify-jwt
```

그다음 대시보드에서 웹훅 연결:

1. **Database → Webhooks → Create a new hook**
2. 이름 `notify-rfq` · Table `rfq` · Events **INSERT 만**
3. Type: **Supabase Edge Functions** → `notify-rfq` 선택
4. HTTP Headers 에 추가: `x-hook-secret` = 위 HOOK_SECRET 값
5. 저장 → 사이트에서 테스트 문의 1건 접수 → Gmail 도착 확인

> 알림이 실패해도 접수는 됩니다 — 함수는 실패를 로그로만 남깁니다
> (Edge Functions → notify-rfq → Logs). 알림이 안 오면 거기부터 보십시오.
