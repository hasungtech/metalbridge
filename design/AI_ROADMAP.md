# AI 로드맵 — 무엇을, 언제, 왜 키우나

v1.0 · 2026-08-25 · 원본은 이 파일 (배포용 서류는 여기서 뽑습니다)

날짜 계획이 아니라 **트리거 계획**입니다. 각 단계는 달력이 아니라 지표가
당깁니다 — 트리거가 안 오면 만들지 않습니다. 지금 트래픽이 0이므로,
날짜로 약속하는 로드맵은 전부 거짓말이 되기 때문입니다.

현재 상태(v0)의 응답 범위는 자동화 지도 문서를 참조:
판독·문답은 브라우저 규칙 엔진, 상담은 키워드 카드 8개, LLM 호출 없음.

---

## 변하지 않는 것 — 모든 단계가 통과해야 하는 게이트 3개

어떤 단계도 이 세 가지를 깨는 방향으로 가지 않습니다. 깨야만 가능해 보이면
그 단계를 버리거나, 운영자가 원칙 개정을 **명시적으로 결정**한 뒤에 갑니다.

1. **단가는 공급처가 냅니다** — AI가 아무리 똑똑해져도 단가·시세를 만들지 않습니다
2. **도면은 승인 없이 나가지 않습니다** — 외부 AI 서버로 도면을 보내는 단계는
   반드시 고객 동의 문구 + 개인정보처리방침 개정(처리 위탁·국외 이전)이 선행됩니다
3. **지어내지 않습니다** — 모든 AI 답변에는 "모르면 담당자 연결" 폴백이 있고,
   폴백 없는 AI 기능은 배포하지 않습니다

---

## 0.5단계 — 계측 (지금, 트리거 없음)

**모든 후속 단계의 트리거가 지표인데, 지금은 지표를 잴 로그가 없습니다.**
그래서 이것만은 트리거 없이 바로 합니다. LLM 없음, 비용 0.

만들 것
- `ai_log` 테이블 (Supabase · anon insert only · 길이 상한) —
  상담 질문 원문 · 매칭된 카드 id 또는 폴백 여부 · 언어 · 시각
- 판독 실패 계측 — 텍스트 입력이 품목으로 안 잡힌 원문, 결손(불가) 품목 비율
- 문답 이탈 계측 — 몇 번째 문항에서 나가는지 (19문항이 긴지 짧은지의 근거)

정의되는 지표
| 지표 | 뜻 | 쓰이는 곳 |
|---|---|---|
| 폴백률 | 상담 질문 중 카드 밖 비율 | 1·3단계 트리거 |
| 판독 확정률 | 텍스트 입력 중 확정 품목이 나온 비율 | 1·2단계 트리거 |
| 이미지 첨부율 | 첨부 중 스캔·사진 비율 | 4단계 트리거 |
| 문항 이탈점 | 문답 중도 이탈이 몰리는 문항 | 문답 다이어트 근거 |

## 1단계 — 규칙 확장 (LLM 없음 · 상시)

지금 구조 그대로 키우는 일. 성격상 "단계"라기보다 운영 루틴입니다.

- 즉답 카드 8 → 20개: **같은 주제 문의 3회**가 카드 1개의 트리거
  (후보: 하스텔로이 C-276/C-22, 듀플렉스 2205, 17-4PH, 동합금 C1100/베릴륨동,
  SKD61/H13, HARDOX, 3.1 vs 3.2 심화, 수입재 통관·원산지 증명)
- 판독 규칙: 폴백·실패 로그를 주 1회 훑어 표기 패턴 추가
  (테스터 3건을 당일 반영한 것과 같은 루프의 정례화)
- 비용 0 · 되돌리기 즉시 · 게이트 저촉 없음

## 2단계 — 백오피스 LLM 보조 (고객 비노출)

**담당자 화면 안에서만** LLM을 씁니다. 고객 화면은 그대로 규칙 엔진 —
틀려도 담당자가 걸러내는 위치에만 AI를 둡니다.

- 트리거: **주간 문의 10건 이상** 또는 **판독 확정률 70% 미만**이 2주 지속
- 만들 것
  - 복잡한 BOM·비정형 첨부 → 품목 구조화 **초안** (담당자 검수 후 확정)
  - 공급처 회신 엑셀 → 비교표 **초안** (형식이 제각각인 회신 정리)
- 모델: `claude-opus-5` 기본. 대량 단순 추출은 `claude-haiku-4-5`,
  급하지 않은 일괄 처리는 Batch API(50% 할인)
- 비용 감: 문의 1건 보조에 수천~수만 토큰. Opus 5 기준 입력 $5/백만·출력
  $25/백만 토큰이라 월 수백 건 규모에서 수만 원대 — 종량이라 안 쓰면 0
- **게이트 2 저촉**: 첨부가 Anthropic API로 전송됩니다. 선행 조건 —
  ① 개인정보처리방침에 처리 위탁·국외 이전 명시 ② 접수 화면 동의 문구
  ③ 백오피스에서 건별 "AI 정리" 버튼(자동 전송 아님 = 담당자의 승인 행위)

## 3단계 — 고객 대면 LLM 상담

상담 위젯이 카드 밖 질문에도 자유 문장으로 답합니다.

- 트리거: **폴백률 50% 이상** 이면서 **월 상담 세션 30건 이상**
  (질문은 많은데 절반을 놓치고 있다는 뜻일 때만)
- 만들 것: KB 카드 + SOURCING_SCOPE + 브랜드 문구 규칙을 그라운딩으로 넣은
  상담. 시스템 프롬프트에 하드 가드레일 — 단가·시세·재고·납기 확답 금지,
  근거 없는 강종 추천 금지, 불확실하면 담당자 연결
- 전 대화 `ai_log` 저장 (오답 리뷰 루프), 첫 달은 베타 표기
- **게이트 1·3 저촉 주의**: 가드레일 회피 테스트(단가를 우회로 묻기)를
  배포 전 체크리스트로. 실패 시 즉시 카드 방식으로 롤백 (플래그 하나)

## 4단계 — 도면 이미지 판독 (비전)

스캔 PDF·사진 도면에서 품목 초안을 뽑습니다. 지금은 "못 읽습니다"라고
정직하게 안내하는 영역.

- 트리거: **이미지형 첨부가 전체 첨부의 30% 이상**
- 만들 것: 이미지 → 품목 초안 → **고객이 화면에서 확인·수정** 후 확정
  (자동 확정 없음 — 오독이 요청서로 직행하는 것을 막습니다)
- 모델: `claude-opus-5` (PDF·이미지 입력 지원)
- 게이트 2 저촉: 2단계와 같은 동의·고지 선행. 도면 원본이 가장 민감한
  자료이므로, 이 단계는 2단계 운영 경험이 쌓인 뒤에만

## 5단계 — 데이터 자산 (해자)

회신이 쌓이면 생기는 것 — 소재·형상별 실제 리드타임 분포, 회신율 높은
공급처, 단가 분포.

- 트리거: **공급처 회신 100건 누적**
- 만들 것: 백오피스 전용 참고 화면 (담당자가 "이 소재는 보통 6~10주"를
  데이터로 아는 것)
- **게이트 1 저촉 — 기본은 고객 비노출.** "예상 단가 범위"를 고객에게
  보여주는 것은 원칙 개정 사안이므로 이 로드맵 범위 밖. 운영자가 그때
  별도로 결정합니다

## 운영 원칙

- 단계를 건너뛰지 않습니다 — 특히 3·4단계는 2단계(사람이 거르는 위치)에서
  오답 패턴을 본 뒤에만
- 분기 1회 이 문서를 지표와 대조합니다 (취급 범위 재검토와 같은 주기)
- 트리거 수치는 운영자가 조정할 수 있습니다 — 고치면 이 파일과
  CHANGELOG 에 남깁니다
