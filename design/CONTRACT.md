# 디자인 ↔ 개발 계약

Design은 이 문서의 항목만 지키면 레이아웃을 자유롭게 바꿀 수 있습니다.

## 1. 필수 DOM 훅

| id | 역할 | 최소 요건 |
|---|---|---|
| `drop` | 파일 드롭 영역 | 클릭 가능 · `.hot` 클래스로 드래그 진입 표시 |
| `fileInput` | 파일 선택 | `<input type="file" multiple hidden>` |
| `askLog` | 대화 로그 | 세로 스크롤 · 자식이 아래로 쌓임 |
| `askChips` | 선택지 | 버튼이 가로로 나열 · 넘치면 줄바꿈 또는 가로 스크롤 |
| `askIn` | 답변 입력 | `<input type="text">` |
| `askSend` | 전송 버튼 | — |
| `askAttach` | 파일 추가 버튼 | — |
| `specBody` | 판독 표 | 표 또는 카드 목록이 들어갈 빈 컨테이너 |
| `specMeta` | 판독 요약 | 한 줄 텍스트 |

## 2. 필수 클래스

| 클래스 | 용도 |
|---|---|
| `.abub.sys` | 시스템 말풍선 (좌측) |
| `.abub.me` | 고객 말풍선 (우측) |
| `.abub .who` | 발신자 라벨 |
| `.abub .mini` | 말풍선 안 보조 설명 |
| `.tag.ok` | 판독 확정 |
| `.tag.warn` | 조건부 |
| `.tag.miss` | 확인 필요 |
| `.rv` / `.rv.in` | 스크롤 리빌 |

## 3. 화면 상태 (모두 디자인 필요)

1. **업로드 전** — 드롭 영역이 비어 있음
2. **판독 중** — "자료를 읽고 있습니다" 말풍선
3. **판독 완료** — 요약 말풍선 + `specBody`에 표가 채워짐
4. **문답 중** — 질문 말풍선 + 해당 품목 목록 + 선택 칩
5. **완료** — 접수번호 + 요청서 내려받기 + 담당자에게 보내기 + 전달 상태
