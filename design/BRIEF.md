## 1. 이 페이지가 해야 할 단 하나

**방문자가 5초 안에 자기 파일을 끌어다 놓게 만드는 것.**

- 계약도 미팅도 문의 폼도 아닙니다. **파일 한 건**입니다.
- 첫 화면(스크롤 없이)에 업로드 영역이 반드시 보여야 합니다.
- 데스크톱·모바일 모두에서 그렇습니다.

## 2. 누가 오는가

부산·경남의 정밀가공사, 금형 제작사, 피팅·밸브 제조사의 **구매 담당자 또는 사장**입니다.

- 40~60대, 현장에서 모바일로 봅니다
- 지금 견적을 기다리는 품목이 손에 있습니다
- 소재 용어를 저희보다 잘 압니다 — 설명하려 들면 신뢰를 잃습니다
- 화려한 것보다 **정확하고 빠른 것**에 반응합니다

## 3. 지금 무엇이 문제인가

| 문제 | 조치 |
|---|---|
| 섹션 11개 · 스크롤이 끝나지 않음 | **5개로 축소** |
| "4개국 동시 견적"이 5번 반복 | 한 번만, 가장 강한 자리에 |
| 3D가 3개(코일·지구본·소재뷰어) · 3MB | **1개만 남김** (히어로) |
| 업로드 영역이 우측에 눌려 있음 | 첫 화면 중앙 또는 좌측 주도 위치로 |
| 판독 예시와 실제 업로드가 분리됨 | **하나로 통합** — 올리면 그 자리에서 결과 |
| 무엇을 파는 곳인지보다 "멋있다"가 먼저 | 첫 문장에서 업(業)이 드러나게 |

## 4. 요구하는 섹션 구조 (5개)

### ① 히어로 — 업로드가 주인공
- 한 줄 정의: 무엇을 해주는 곳인지 (예: "소재 견적, 저희가 대신 받아드립니다")
- **업로드 영역이 화면에서 가장 큰 요소**여야 합니다
- 파일이 없는 사람을 위한 텍스트 입력도 같은 자리에
- 3D 금속 오브젝트는 배경 보조로만 — 업로드를 가리지 않게
- 신뢰 근거 4개를 작은 사양표로 (취급 소재 / 공급망 / 접수 형식 / 확인 절차)

### ② 올리면 이렇게 됩니다 — 결과 미리보기
- 판독 표(재질·형상·치수·수량·판독 상태)가 실제로 채워지는 화면
- 확정 / 조건부 / 확인 필요 세 상태가 색으로 구분
- **①에서 파일을 올리면 이 영역이 채워집니다** — 별도 데모 섹션이 아님

### ③ 대화로 채웁니다 — 확인 문답
- 채팅 형태. 빠진 항목을 묻고 답하면 ②의 표가 갱신됨
- 말풍선·입력줄·선택 칩

### ④ 어디에 물어보는가 — 공급망
- 한국·중국·일본·인도. **여기서 "4개국"을 한 번만** 강조
- 지구본을 쓸지 지도·리스트로 바꿀지는 자유. 로딩이 무거우면 버려도 됨

### ⑤ 마무리 — 문의 유도 + 최소 FAQ
- 다시 업로드로 보내는 CTA
- FAQ는 3개까지 (보안 / 소량 가능 / 소요 기간)

**삭제 대상**: 누가 쓰나, 작동 방식 4단계, 진행 현황, 취급 소재 3D 뷰어, AI 상담 섹션
(AI 상담은 우측 하단 떠 있는 버튼으로만 유지)

## 5. 반드시 유지해야 하는 것 — 개발 연결점

레이아웃은 자유롭게 바꾸되, **아래 id를 가진 요소는 반드시 존재해야 합니다.**
엔진이 이 이름으로 화면을 찾습니다.

| id | 역할 |
|---|---|
| `drop` | 파일 드롭 영역 (클릭 시 파일 선택) |
| `fileInput` | `<input type="file" multiple hidden>` |
| `askLog` | 대화 말풍선이 쌓이는 컨테이너 |
| `askChips` | 선택지 버튼이 그려지는 줄 |
| `askIn` | 답변 입력 `<input type="text">` |
| `specBody` | 판독 결과 표가 그려지는 영역 |
| `specMeta` | "품목 20건 · 확정 2 · 조건부 12" 요약 문구 |

말풍선 클래스도 유지: `.abub.sys`(시스템) / `.abub.me`(고객)
판독 상태 태그: `.tag.ok` / `.tag.warn` / `.tag.miss`

## 6. 디자인 토큰 (기존 유지)

```
--ink        #0e0e10   주 텍스트 · 어두운 면
--canvas     #ffffff   배경
--cloud      #f5f5f5   보조 면
--hairline   #cacacb   구분선
--mute       #707072   보조 텍스트
--brand      #0f62fe   IBM Blue 60 — 강조 (전체의 5% 이내)
--brand-hi   #4589ff
--brand-deep #002d9c   눌림 상태
--success    #198038
--pill       30px      버튼 반경
```

- 서체: Pretendard(국문) + Anton(영문 대문자 헤드라인)
- 형태 어휘는 **각진 카드 + 알약형 버튼** 두 가지만
- 그림자 금지. 구분은 1px 헤어라인으로
- 파란색은 강조에만. 면으로 크게 쓰지 말 것
