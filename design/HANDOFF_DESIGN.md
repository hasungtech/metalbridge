# METAL BRIDGE 메인 페이지 디자인 의뢰

> 이 문서 전체를 Claude Design에 그대로 붙여넣으십시오.

---

## 무엇을 만드는가

**METAL BRIDGE (metalbridge.ai)** — 특수 소재 견적 중개 서비스의 메인 페이지를 다시 설계합니다.
제조사가 도면·BOM·메시지를 올리면 사양서로 정리해, 한국·중국·일본·인도 공급망에 동시에 견적을 요청하고 비교표로 돌려주는 서비스입니다.

운영: Grit Corporation

## 이 페이지가 해야 할 단 하나

**방문자가 5초 안에 자기 파일을 끌어다 놓게 만드는 것.**

- 계약도, 미팅 예약도, 상담 신청도 아닙니다. **파일 한 건**입니다
- 첫 화면(스크롤 없이)에 업로드 영역이 반드시 보여야 합니다
- 데스크톱(1440)과 모바일(390) 모두에서 그렇습니다

## 누가 오는가

부산·경남의 정밀가공사, 금형 제작사, 피팅·밸브 제조사의 **구매 담당자 또는 사장**입니다.

- 40~60대, 현장에서 휴대폰으로 봅니다
- 지금 견적을 기다리는 품목이 손에 있습니다
- 소재 용어를 우리보다 잘 압니다. 가르치려 들면 신뢰를 잃습니다
- 화려한 것보다 **정확하고 빠른 것**에 반응합니다

## 지금 무엇이 문제인가

현재 페이지는 이렇게 잘못돼 있습니다.

| 문제 | 조치 |
|---|---|
| 섹션이 11개, 스크롤이 끝나지 않음 | **5개로 축소** |
| "4개국 동시 견적"이 다섯 번 반복됨 | 가장 강한 자리에 **한 번만** |
| 3D가 3개(코일·지구본·소재뷰어), 총 3MB | **1개만 남김** |
| 업로드 영역이 우측에 눌려 있음 | 첫 화면의 **주인공**으로 |
| 판독 예시 섹션과 실제 업로드가 분리됨 | **하나로 통합** |
| 무엇을 파는 곳인지보다 "멋있다"가 먼저 옴 | 첫 문장에서 업(業)이 드러나게 |

## 요구하는 구조 — 5개 섹션

### ① 히어로 — 업로드가 주인공

- 한 줄 정의 (예: "소재 견적, 저희가 대신 받아드립니다")
- **업로드 영역이 화면에서 가장 큰 요소**
- 파일이 없는 사람을 위한 텍스트 입력도 같은 자리에
- 3D 금속 오브젝트는 배경 보조로만. 업로드를 가리지 않게
- 신뢰 근거 4개를 작은 사양표로:
  취급 소재 / 공급망 / 접수 형식 / 확인 절차

### ② 올리면 이렇게 됩니다 — 판독 결과

- 표: 재질 · 형상 · 치수 · 수량 · 판독 상태
- 상태 3종을 색으로 구분: **확정 / 조건부 / 확인 필요**
- ①에서 파일을 올리면 **이 영역이 채워집니다**. 별도 데모 섹션이 아닙니다

### ③ 대화로 채웁니다 — 확인 문답

- 채팅 형태. 시스템 말풍선(좌) / 고객 말풍선(우)
- 빠진 항목을 묻고, 답하면 ②의 표가 갱신됨
- 말풍선 안에 "해당 품목 11건" 목록이 들어감
- 하단에 입력줄 + 선택지 칩 + 파일 추가 버튼

### ④ 어디에 물어보는가 — 공급망

- 한국·중국·일본·인도. **여기서 "4개국"을 한 번만** 강조
- 지구본을 쓸지 지도·리스트로 바꿀지는 자유. 무거우면 버려도 됩니다

### ⑤ 마무리 — 문의 유도 + FAQ 3개

- 다시 업로드로 보내는 CTA
- FAQ는 3개까지: 보안 / 소량 가능 / 소요 기간

**삭제 대상**: 누가 쓰나 · 작동 방식 4단계 · 진행 현황 · 취급 소재 3D 뷰어 · AI 상담 섹션
(AI 상담은 우측 하단 떠 있는 버튼으로만 유지)

## 반드시 그려주셔야 할 화면 상태 5개

히어로 영역은 정적인 한 장면이 아닙니다. 아래 5개를 모두 그려 주십시오.

1. **업로드 전** — 드롭 영역이 비어 있음
2. **판독 중** — "자료를 읽고 있습니다" 말풍선
3. **판독 완료** — 요약 말풍선 + 표가 채워짐
4. **문답 중** — 질문 말풍선 + 해당 품목 목록 + 선택 칩
5. **완료** — 접수번호 + 요청서 내려받기 + 담당자에게 보내기 + 전달 상태 표시

## 디자인 토큰 (그대로 사용)

```
--ink        #0e0e10   주 텍스트 · 어두운 면
--canvas     #ffffff   배경
--cloud      #f5f5f5   보조 면
--hairline   #cacacb   구분선
--mute       #707072   보조 텍스트
--brand      #0f62fe   IBM Blue 60 · 강조 전용
--brand-hi   #4589ff
--brand-deep #002d9c   눌림 상태
--success    #198038
--pill       30px      버튼 반경
```

- 서체: **Pretendard**(국문) + **Anton**(영문 대문자 헤드라인) + **JetBrains Mono**(치수·번호)
- 형태 어휘는 **각진 카드 + 알약형 버튼** 두 가지만
- **그림자 금지.** 구분은 1px 헤어라인으로
- 파란색은 **전체 면적의 5% 이내**. 면으로 크게 쓰지 마십시오

## 톤

- 산업재 카탈로그의 정확함. 스타트업 랜딩페이지 문법 금지
- **검증되지 않은 큰 숫자 금지** (예: "48시간 회신", "만족도 98%")
- "최고의 파트너", "혁신적인" 같은 표현 금지
- 이모지 금지
- 문장은 짧고 단정적으로

## 개발 연결 조건 (레이아웃은 자유, 이것만 지켜주십시오)

이 화면은 이미 동작하는 파싱 엔진에 붙습니다. 아래 요소가 반드시 존재해야 합니다.

| 요소 | 역할 |
|---|---|
| 파일 드롭 영역 | 클릭 가능 · 드래그 진입 시 상태 변화 |
| 숨겨진 파일 입력 | 다중 선택 |
| 대화 로그 컨테이너 | 세로 스크롤 · 아래로 쌓임 |
| 선택지 버튼 줄 | 넘치면 줄바꿈 또는 가로 스크롤 |
| 답변 입력창 + 전송 버튼 + 파일 추가 버튼 | — |
| 판독 표 컨테이너 | 표 또는 카드 목록 |
| 판독 요약 문구 | 한 줄 텍스트 |

말풍선은 시스템/고객 2종, 판독 태그는 확정/조건부/확인 필요 3종이 구분되어야 합니다.
