# 3D 워드마크 시안

문의 화면 뒤에 METAL BRIDGE 워드마크를 압출된 강재로 세우는 안입니다.
**아직 채택 전입니다.** 본문(`index.html`)에는 들어가 있지 않습니다.

`PROTOTYPE.html` 한 장을 브라우저로 열면 그대로 돌아갑니다.
조절판에서 마감·자리·움직임·두께·크기·선명도를 바꿔 보고,
맨 아래 한 줄(예: `마감 헤어라인 · 자리 배경 · 움직임 마우스 · 두께 30 …`)을
그대로 전달하면 그 조합으로 구현합니다.

## 어떻게 그리는가

워드마크를 마스크 캔버스로 한 번 굽고, 깊이별 단면을 정사영 행렬로 겹쳐 그립니다.
각도마다 옆면이 다시 계산되므로 미리 렌더한 이미지가 아니라 실제 3D 압출입니다.

```
X = x·cos(yaw) + z·sin(yaw)
Y = x·sin(yaw)·sin(pitch) + y·cos(pitch) − z·cos(yaw)·sin(pitch)
```

canvas 의 `setTransform(m11,m12,m21,m22,dx,dy)` 에 그대로 대응합니다.

## 채택할 때 지킬 것

- **3D 라이브러리를 들이지 않습니다.** 지구본과 같은 Canvas 2D 한 장입니다
  (CLAUDE.md 화면 구성 규칙). three.js 를 다시 넣지 마십시오
- **단면은 불투명하게 쌓고 화면에는 한 번만 얹습니다.** 단면마다 알파를 주면
  30장이 누적돼 선명도 조절이 먹히지 않습니다 (오프스크린 버퍼)
- 파란색은 로고의 마침표와 광 한 줄에만. 면적 5% 규칙 안에 둡니다
- 그림자를 쓰지 않습니다. 명암은 옆면 6단계로만 만듭니다
- 색은 `src/styles/tokens.css` 값을 그대로 씁니다
- 화면 밖으로 나가면 루프를 멈춥니다 (`IntersectionObserver`)
- `prefers-reduced-motion` 이면 따라오기·자동회전을 끕니다

## 정해야 할 것

1. 자리 — 배경 / 우측 걸침 / 전면
2. 선명도 — 40% 를 넘기면 뒤의 문구를 읽는 데 방해가 됩니다
3. 움직임 — 마우스 / 자동 / 고정
4. 적용 범위 — 문의창만인지, 회사 소개에도 둘지, 파비콘까지 갈지
