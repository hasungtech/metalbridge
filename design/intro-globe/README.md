# 소개 화면 지구본 — 채택·반영 완료

`#intro` 오른쪽의 "저희가 대신하는 일" 4행 표 자리에 지구본을 올리는 안이었습니다.
**결정되어 본문에 들어갔습니다.** 시안 파일(`PROTOTYPE.html`)은 역할을 다해 지웠습니다 —
되살리려면 git 이력에 있습니다.

## 확정된 조합

| 항목 | 결정 |
|---|---|
| 지구본 크기 | 크게 걸침 — 오른쪽으로 잘려 나갑니다 |
| 4행 목록 | 한 줄로 압축 (CTA 아래) |
| 거래 흐름 화면 | 지구본 제거, 권역 4열 카드로 넓게 |
| 휴대폰 | 지구본 표시 — 단, 문구 뒤가 아니라 아래에 한 장으로 |

## 구현 위치

- 마크업 `index.html` 의 `#intro > .globe-stage`
- 배치 `src/ui/scene3d.js` — 넓은 화면 `cx=0.78w · R=0.70·min(w,h)`, 좁은 화면은 가운데
- 스타일 `src/styles/base.css` 의 `.intro` · `.globe-stage` · `.zones`

## 지킬 것

- **지구본은 소개 화면에 하나뿐입니다.** 거래 흐름에 다시 두면 스크롤 두 번에
  같은 그림을 또 보게 됩니다 (CLAUDE.md 화면 구성 규칙)
- 3D 라이브러리를 들이지 않습니다. Canvas 2D 한 장입니다
- 권역 카드의 숫자는 `SUPPLIER_MASTER` 에서 셉니다 (`supplierCount()`)
