# 소개 화면 지구본 배치안

소개 화면(`#intro`) 오른쪽의 "저희가 대신하는 일" 4행 표 자리에 지구본을 올리는 안입니다.
**아직 채택 전입니다.** `index.html` 에는 들어가 있지 않습니다.

`PROTOTYPE.html` 한 장을 브라우저로 열면 그대로 돌아갑니다. 배치 4안을 화면에서 바꿔 보고,
맨 아래 한 줄을 그대로 전달하면 그 조합으로 구현합니다.

| 배치 | 내용 |
|---|---|
| 지금(표) | 현재 상태. 비교 기준 |
| 우측 지구본 | 표 자리를 지구본이 차지. 4행은 CTA 아래 한 줄로 |
| 크게 걸침 | 지구본을 오른쪽으로 크게 걸쳐 잘라냄. 가장 셈 |
| 배경 | 전체 폭에 옅게 깔기. 권하지 않음 — 장식이 됩니다 |

## 구현 방법

시안은 혼자 돌아가야 해서 해안선을 파일에 박아 넣었지만,
**본문에 넣을 때는 그러지 마십시오.** `src/ui/scene3d.js` 의 `initScene()` 을
캔버스 id 와 배치 인자를 받도록 열어 소개 화면에서 한 번 더 부르면 됩니다.
지리 데이터(`public/geo/countries-110m.json`)는 이미 받아둔 것을 함께 씁니다 —
번들도 요청도 늘지 않습니다.

## 걸리는 점

- **같은 지구본을 두 번 보게 됩니다.** 거래 흐름 화면(`#flow`)에도 있습니다.
  둘 중 하나는 성격을 바꾸는 편이 낫습니다 — 아래를 권역 표만 남기거나,
  위를 라벨 없이 두거나
- **모바일에서는 표가 낫습니다.** 가로 900 아래에서 두 열이 한 열로 접히면
  지구본이 정사각형으로 자리를 크게 먹습니다. 접어서 4행만 보이게 하십시오
- 4행 목록을 한 줄로 줄이면 "무엇을 대신해 주는지"가 약해집니다.
  소개 화면이 하려던 일이 바로 그것이었습니다
